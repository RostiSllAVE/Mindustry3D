MINDUSTRY3 / FPV - ALPHA 2.0.0 RC1 (MOD 0.19.0)
LOCAL RELEASE CANDIDATE - NOT A PUBLISHED RELEASE

Unofficial experimental fan-made mod. Install Mindustry 160.7 separately.
Primary target: Windows 64-bit. Linux desktop RC acceptance is pending.
Android is unsupported. No separate Java, JDK, Python or developer files needed.

1. Back up saves. In Mindustry open Mods > Import Mod > Import File.
2. Select mindustry-fpv-0.19.0.jar; accept replacement of the previous mod.
3. Enable only ONE copy; do not combine Workshop and imported versions.
4. Restart Mindustry normally, through its standalone launcher or Steam.
5. Use Fullscreen; open a disposable map and press F5, then Tab for Build Mode.

Convenience ZIP: extract it, then import the JAR inside.
Do not import the corresponding-source ZIP or Workshop upload ZIP.
Workshop/Mod Browser availability of this RC cannot be tested until an approved
publication. Existing public releases are unchanged by this local preparation.

F5: 2D/FPV. Tab: Build/flight. F7: camera. Alt+F7: smoothing. Alt+wheel: distance.
F9: flight mode. F3: pause/resume construction without deleting plans.
F4 in Build: 3D selection; drag XY and wheel for Z. Use its Copy/Paste buttons.
Click a blueprint to prioritize; Alt+click when a placement tool is selected.
Menus, Build Mode and focus loss release capture. See README for other bindings.

KNOWN LIMITATIONS
Windowed mode caused severe stalls on the owner's Windows hardware; fullscreen
removed them in that test. Cosmetic/LOD approximations and custom-mod issues
remain possible. Linux mouse capture/compositor and two-laptop networking need
owner acceptance. If HOST MOUSE appears, native capture was unavailable and mouse
look is bounded; keyboard look remains. All peers need the exact matching build.
No independent internet multiplayer certification or universal FPS claim is made.
