# A2-16l — Owner manual acceptance (three steps)

Import `mindustry-fpv-a2-16l-diagnostics.jar` using Mindustry 160.7 Mods → Import Mod, replace the previous diagnostic copy, restart and enable only one Mindustry³ copy. Back up any save you choose to use. Windows fullscreen is recommended because of the previously documented windowed presentation issue. The host game is installed separately; this is not a standalone game. The same diagnostic JAR targets supported Windows/Linux desktop hosts. No new keys or configuration are needed.

1. **Recheck six original factories.** In a disposable sandbox, run Ground/Air/Naval Factory and Tank/Ship/Mech Fabricator with valid resources, power and output terrain. Inspect top, low side and oblique FPV views while producing, waiting with a completed payload and disabled. Watch the cyan nozzles move with their metal arms, fixed strips sit on housings, and bay textures stay separated. Check F5 and Tab both ways.
2. **Upgrade real input units.** Feed all four Serpulo reconstructors and four Erekir refabricators using normal payload transport, power/resources/liquids and native upgrade rules. Verify input arrival, progress, moving tools, idle/blocked behavior, correct upgraded output and one normal resource charge. Rotate several bays. Naval output requires valid water; a dry platform should hold it rather than spawn it. No special shortcut or instant-unit feature was added.
3. **Check floor integration and persistence.** Put supported bays on a valid elevated structure with enough headroom (large bays need more than one level), view from above/below, try existing 3D copy/paste and save/reload. Confirm unchanged construction pause/priority controls and old models. If testing multiplayer, use the exact same JAR on both peers; separately report remote upper animation, which is not certified. Note block, floor, active/idle state and view if clipping remains.

Physical acceptance is pending. Automated native/graphics tests do not certify Linux mouse behavior, physical campaign transitions or two-computer networking. The source ZIP is GPL corresponding source, not the file to import as the mod.
