# A2-15b.2 — Interactive background painter

Baseline: accepted A2-15b `7093055`, existing `main`. The initial bounded editor, presets and per-map storage already existed; this pass extends them instead of rebuilding them.

## Internal checkpoint 1 — brush data and geometry

Added gesture-scoped strength, Raise/Lower/Smooth/Flatten, distinct Shallow Water and Lake brushes, and sparse Industrial motifs. A gesture stores its source mask and maximum influence per node, so repeated pointer events or holding still do not amplify a stroke. Strength blends up to two material identities per node without reopening holes in islands. Height tools use the original base terrain and a fixed pre-stroke snapshot; smooth reads neighbours from that snapshot. Height is bounded by brush radius and the existing 240-tile limit; custom relief is also tapered near the native border. Broader custom shoreline ramps prevent abrupt full-height shore walls. Auto/Manual generation is unchanged.

Painted Grass uses shrub LOD; Forest retains tree silhouettes. Painted sand/rock/volcanic regions can receive bounded outcrops; Industrial creates at most six decorative mesh motifs, no buildings/entities. These use the existing cached scenery mesh and feature machinery.

Local profile v2 adds a second material ID and blend weight. Maximum reads are 192KiB, populated profile142,642 bytes; mask142,578 bytes and bounded32-stroke history estimate4,847,652 bytes. Exact v1 channel migration and v2 roundtrip are tested; old profiles remain readable and ordinary saves/network protocol are untouched. At most two materials per node are retained: a third overpaint uses the previous dominant material, not an unlimited Photoshop-style layer stack.

Targeted validation:22 programs on Java17 and stock Steam25; additional detail/height fixture passes1,921,233 checks on Java17. Brush fixture passes8,561 checks. Full final suites and physical acceptance are reported separately after the UI/viewport checkpoint. Intermediate graphics exposed incorrect Arc framebuffer nesting; corrected before final validation. The first 960×600 viewport render also exposed wrapping/width problems, being corrected in the UI checkpoint.

## Final editor and preview

The modal editor now has a working **Preview 3D** viewport and **Edit map** return button. It uses the existing `EnvironmentRenderer`/cached horizon mesh, its own orbit camera and one reused depth framebuffer, capped uniformly to960×600 to preserve aspect at high DPI. The central native map is a read-only flat reference image; surrounding scenery is the actual generated3D mesh. It does not borrow the FPV camera, controller, unit or a second SDL instance. The sky's aspect now comes from its supplied camera so a non-fullscreen viewport has correct perspective. Ordinary full-window camera dimensions yield the same behavior.

The viewport restores Arc framebuffer nesting plus GL viewport, scissor, stencil, depth/write/function, blend factors/equations, program, clear color, active texture and borrowed texture bindings. Its target, map-reference mesh, shader and environment meshes are disposed on close; it does not own the borrowed map texture. Reopening/closing and switching maps retain the existing profile-context guard. An actual graphics fixture caught a missing `end()` before this final implementation; the failed intermediate run is retained locally. Subsequent real SDL frames pass without GL errors. Orbit/zoom never regenerate the scenery mesh.

**Exact controls:** open **Tab → Background settings → Open Background Editor**, also available under **Settings → FPV flight** in a loaded world. LMB-drag paints; RMB/MMB-drag pans; wheel zooms at the cursor. Palette scrolls independently. Radius is in native tiles. Strength controls opacity/sculpt amount; Falloff specifies hard inner radius. Height/step shows the effective radius-limited target. Ctrl+Z undoes; Ctrl+Y or Ctrl+Shift+Z redoes. **Preview 3D** snapshots staged paint; in that view LMB-drag orbits, RMB/MMB-drag pans and wheel changes distance. **Edit map** returns to painting. Further strokes need Preview3D again. **Apply** persists; **Cancel**/Escape discards uncommitted edits/preview, not an earlier Apply. **Clear** is staged/undoable; **Reset Auto** explicitly applies Auto but retains the mask. The eraser restores the chosen base (Auto when entered from Auto; the manual preset when entered from Manual).

One gesture is event-rate independent; separate weak gestures accumulate. Rounded Mountain/Hill cross-sections and sloping Island skirts avoid the flat plateau/stiff coast from the initial new tool. This changes only newly painted strokes, not stored height samples. Raise/Lower use a height step; Flatten uses an absolute visual height; Smooth ignores the height slider and samples the pre-stroke neighbourhood. Height-only tools operate on land: use Island/material first when creating land in an ocean. Water always stays a separate horizontal surface; Shallow caps the bed at0.8 tiles, Lake at4, Ocean retains the established increasing depth/darkening. New art never changes physical terrain, diving, construction or pathfinding.
