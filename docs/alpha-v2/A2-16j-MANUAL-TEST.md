Import `mindustry-fpv-a2-16j-diagnostics.jar` through **Mods → Import Mod**, replace the previous diagnostic copy, restart Mindustry160.7 and enable one copy. Compare their size, silhouette, team markings and resource openings from above, from the side and at low FPV height. Check adjacency and view a core through an opening in an elevated platform.
2. **Core behavior:** upgrade an existing core normally, confirm resources/storage and the original respawn unit, then save/reload and revisit a campaign sector. Confirm F5/Tab, inspection and building still work. No new respawn/launch control or synchronized spawn effect is introduced.
3. **Utilities and recent fixes:** power Radar on/off and check that the dish follows scanning; check Illuminator colour/light and valid elevated placement or copied utility groups on Z1/Z3–Z5. Revisit Wave/Tsunami with water/slag and Cyclone firing to physically accept the preceding turret fix alongside this build.

Do not use editor/test-fixture placement as proof that a core is allowed on a construction floor. This pass leaves existing native/server restrictions intact. For a multiplayer check, use matching JARs on both computers and separately inspect upper-floor Radar animation; host/local animation is verified, while remote upper scan-clock presentation is not certified.
