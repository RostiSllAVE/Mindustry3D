# A2-15c.1 — sky controls, map seam and downward island volume

Baseline: A2-15c `7024d605a939d01824a50a6689feb6c3635b5bca`, current branch `main`.
No push, publication, Workshop update or previous artifact replacement.

## Changes and confirmed cause

The previous native-to-background apron deliberately skipped native Space/Empty tiles
and fully cosmic outer samples. The remaining four-tile strip displayed the light sky,
creating a wide rectangular contour. It was not a rendered boundary line. A cached,
batched cosmic apron now fills that strip, using the same direction/parallax material
as the floor and distant field. It adds no playable tiles or collision. A separate thin
outline is optional, depth-tested and OFF by default. The 2D editor map guide stays.

`BackgroundSkyControls` exposes planet, sun, day/night animation, fixed visual time,
full space and map outline in the existing Background Editor. Editor changes remain
staged through Preview/Apply/Cancel. Quick Background settings can apply them directly.
`BackgroundStyle` copies/fingerprints all controls; local profile version3 stores flags
and time. Existing v1/v2 profiles retain legacy sky defaults and paint. Normal profile
backup/recovery remains in place. Native save chunks and network packets are unchanged.

Full space replaces the atmospheric sky and background landscape with cosmic scenery,
while planet/sun remain independently selectable. Stored non-space painting is retained
and restored when full space is disabled. Frozen visual time changes sun/light only,
not native game time, F3 or construction progress. Native campaign/day-clock behavior
continues when animation is enabled. The sun disk is no longer accidentally erased by
applying the cosmic sky after drawing celestial objects.

`SpaceIslandGeometry` builds a deterministic tapered underside near real cosmic floors.
A bounded padded distance field supplies depth, shared grid nodes prevent chunk cracks,
and original floor regions texture the lower surface and sloped edge faces. Upper floor
meshes, materials, placement heights and physics remain unchanged. No undersides on maps
without a nearby native cosmic floor; liquids are excluded. The reach is eight tiles,
with depth below eight tiles. This is edge volume, not a fully solid voxel asteroid or
an interior/underground simulation for arbitrarily large islands.

The original Z0 cosmic floor/depth mask would hide downward geometry. While the cosmic
material is available, the world renderer omits that native flat visual floor (detail
and coarse paths), draws the cosmic mask without depth writes, and then draws undersides
with normal depth. Real terrain, structures and units retain depth testing. OFF or
failed floor material restores the native floor and drops the undersides; toggling
invalidates the appropriate cached floor geometry. No depth buffer clears or stencil
requirements are introduced. Negative geometry extends visual culling bounds only.

Meshes are cached in the existing32MiB cosmic presentation budget, with disposal on
world changes/shutdown. Fog checks include the padded neighbourhood; nearby floor edits
invalidate affected chunks. No per-frame texture or underside mesh generation, new
assets/natives, unit movement, combat, collision or construction changes.

## Verification and limits

See the test matrix/validation JSON for exact matching build evidence. Existing gameplay
classes outside the approved visual/profile/UI scope are byte-identical to A2-15c.
Scripted SDL checks exercise real checkbox/slider events, profile Apply/reload, save/load,
clock freezing, map/entity immutability, platforms, underside views and cached meshes.
Pixel comparisons verify planet/sun/outline change the actual rendered image.

Physical owner gameplay, Linux mouse/rendering and two-computer acceptance are NOT TESTED.
The map outline can become faint at distance; the underwater/void camera in one scripted
view is diagnostic and does not grant negative-Z movement. Existing collision continues
to use the native floor. The painter's flat central reference does not display the real
island body. Pre-existing windowed-mode performance caveats remain.

Initial lab failures were fixture errors: a wall overlapped the test core; a seam test
compared the termination of an eight-tile detail band rather than a shared covered
edge; the sun-view camera was inside a Z3 platform. Fixtures were corrected and rerun;
the final JAR retains the ordinary SmokeHarness, not the laboratory replacement.
