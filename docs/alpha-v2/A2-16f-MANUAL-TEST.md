# A2-16f — Three owner checks

Import `local/a2-16f/test-kit-final2/mindustry-fpv-a2-16f-diagnostics.jar` through
Mindustry 160.7 **Mods → Import Mod**, replace the local test version and restart.
Use a disposable sandbox or a backup of a save. Windows fullscreen remains
recommended. The same JAR is provided for Windows/Linux; Linux physical testing
is still required. The corresponding-source ZIP is not the importable mod.

1. **Production and state.** Build Cryofluid Mixer, Melter, Spore Press, Coal
   Centrifuge, Cultivator, Water Extractor, Oil Extractor and Pulverizer with normal
   inputs, power, valid substrate and connected outputs. Inspect above, obliquely
   and from low FPV. Watch mixing, crushing, pressing, pumping and supported spore
   growth; compare empty/partial/full vessels. Remove power/input, clog output,
   disable/re-enable, then pause with F3. Machinery should follow real native
   activity; output/rates remain normal. Check independent water/cryofluid vessels.
2. **Upper floors and clipboard.** Put representative machines on valid platforms
   at Z1, Z3 and Z5, with sufficient headroom; also inspect an offset Z4 platform
   and the underside. Copy/paste a mixed multilevel structure using existing
   controls. Unsupported/occupied positions must still be rejected; copies must
   require normal construction and must not clone live resources.
3. **Mixed field and return.** Place many new machines beside accepted A2-16d/e
   factories, drills, belts, conduits and power. Compare near/far detail, production
   and resource transfer. Try F5, Tab, configuration and menus; save, reload and
   enter another campaign sector. Report clipping, floating parts, stalls or FPS
   changes. For multiplayer, use identical JARs on both machines; actual remote
   acceptance has not been performed by this task.

Record Windows/Linux, host runtime, block, floor, operating state and view angle
for any problem. Scripted screenshots and tests are evidence, not physical acceptance.
