# A2-16a — Three owner checks

1. Import `mindustry-fpv-a2-16a-diagnostics.jar`, keep one enabled copy and restart.
   On a disposable ore map, build Mechanical, Pneumatic, Laser and Airblast drills;
   supply their usual power/liquids and output space. Inspect each from above in
   Tab/Build Mode and at low/oblique FPV angles.
2. Watch working heads/rods, then disable a drill or block its output and wait for
   native coast-down. Confirm no full-power idle motion, normal ore production,
   readable original textures and no floating/clipping. Try a drill on an allowed
   upper platform and inspect it near visually uneven terrain.
3. Test a larger drill field for acceptable performance, F3 pause, F5/Tab and
   ordinary building controls, then save/reload and enter another sector/map.
   Report unit/view, approximate drill count, angle and fullscreen FPS if a
   slowdown appears. This last check is especially useful for the denser new
   close-up geometry. On Linux, repeat the same steps; Linux physical acceptance
   is pending.

No new controls. Fullscreen remains recommended on Windows due to the existing
windowed-presentation issue. Actual two-computer multiplayer is a separate check
and requires identical diagnostic JARs. The source ZIP is not the importable mod.
