# A2-15b — Owner visual acceptance

Use the local `mindustry-fpv-a2-15b-diagnostics.jar` on a backed-up/disposable Mindustry160.7 profile. Import through Mods → Import Mod, replace the one enabled diagnostic copy and restart. Windows/Linux use the same JAR. Fullscreen remains recommended for the previously confirmed Windows windowed-mode problem. This is a local diagnostic, not a published Alpha replacement.

1. **Depth and presets.** On a water/deep-water map, press F5. At low altitude and below the water surface, inspect the native deep-water bed approaching the border. It should descend gradually and continue into a deeper background ocean. This changes visual depth; the existing physical dive limit remains. Open **Tab → Background settings** (also **Settings → FPV flight**). Switch Auto/Manual, try Ocean/Forest and opposite N/S presets. Check that only outside scenery changes. Try whole-world Space/Void; return to Auto.
2. **Paint a world.** Select Manual Ocean, then Custom and **Open Background Editor**. North is up, native map is inside the white read-only rectangle. LMB-drag Island outside the north edge; choose Forest and paint inside it. Add a Mountain ridge farther away, adjust Height, try Beach and shallow Lake. Radius is in vanilla tiles; larger far-away patches suit the bounded grid. LMB over the native map must do nothing there. RMB/MMB-drag pans; wheel zooms at the cursor. These controls apply only inside this dialog.
3. **Preview and undo.** Ctrl+Z / Ctrl+Y or the Undo/Redo buttons restore strokes (Ctrl+Shift+Z also redoes). Preview shows staged scenery in 3D without saving. Close/Escape restores the applied design. Reopen, paint and Apply; confirm the saved-local status. Clear paint is undoable/staged until Apply. Reset to Auto applies Auto immediately but retains the mask; Custom restores it. No blocks or resources should change.
4. **Persistence and controls.** Save/quit/restart/reload; the applied Custom background should remain. Open a different map/sector, apply a different preset, then return to the first. Check F5, flight mouse capture, Tab, F3, Alt-click blueprint priority, normal placement/removal, selection/copy and menu/Alt+Tab transitions. On Linux also check modal mouse release/capture in the actual X11/Wayland session. With a friend, different local scenery should not affect authoritative play; physical two-computer testing is still pending.

Report map/sector, mode/brush and viewing angle if a seam, misplaced island, input conflict or unsaved profile appears. A screenshot helps distinguish the native map from painted scenery. Local settings live under the current Mindustry data folder in `mindustry3-backgrounds`; `.bak` is the previous valid profile. Do not edit native saves to reset scenery; use Auto/Clear in the UI. Identical named terrain clones share art; renaming or changing sampled native floors can select a new profile. Disk/profile-limit errors explicitly leave changes session-only.
