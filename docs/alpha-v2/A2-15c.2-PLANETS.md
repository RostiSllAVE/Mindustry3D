# A2-15c.2 — Independent Serpulo and Erekir sky visibility

Baseline: owner-accepted `86a418114b070e317f09c195cbda6f7396295665`, branch `main`.
Local diagnostic only. No push, publishing, Workshop changes or release replacement.

## Change

Background Editor → **Sky / map appearance** now has **Show Serpulo** and
**Show Erekir**. Both can be enabled, either alone, or neither. These controls also
appear in the quick Background settings submenu. Editor changes remain staged
until Preview / Apply; the quick settings retain immediate application.

The existing companion keeps its original direction, palette and visibility:
Erekir on Serpulo/default maps, Serpulo on Erekir. The second decorative body uses
the other native planet palette, 58° farther in azimuth and 10° lower in elevation
(clamped to 12–65°). Labels always refer to the actual displayed planet. This is
an artistic sky customization, not orbital simulation, including when showing
the same planet the player is on. The additional body starts hidden.

Both use the same procedural sphere material inside the existing sky pass, with
independent visibility uniforms. No added texture dependency, geometry generation,
draw call, game tile, save chunk or network packet. No FPS improvement is claimed.

Local background profiles advance from v3 to v4 using the unused flag bit 32;
v1–v3 remain readable. The old companion flag retains its meaning on either host
planet. Other sky, paint and time settings are preserved. Apply saves locally
with the existing atomic-write/backup behavior. Older mod builds cannot read v4
profiles; use their retained prior local backup when rolling back appearance data.
Native Mindustry saves are unchanged.

## Owner check

1. Import `mindustry-fpv-a2-15c-planets-diagnostics.jar` through Mods → Import Mod,
   keep one enabled copy, and restart. On Windows, fullscreen remains recommended.
2. Open a map, press Tab, open Background Editor → Sky / map appearance. Enable
   **Show Serpulo** and **Show Erekir**, return and Preview / Apply. Look around:
   the orange Erekir and purple Serpulo occupy separate parts of the sky.
3. Hide each separately, try Full space, then reload the map and confirm the
   applied choices persist. Canceling the editor should restore the prior choices.

The corresponding-source ZIP is source, not the importable mod. All artifacts are
under `local/a2-15c-planets/`, separate from published Alpha releases. Other peers
must use the exact same diagnostic JAR if testing multiplayer.
