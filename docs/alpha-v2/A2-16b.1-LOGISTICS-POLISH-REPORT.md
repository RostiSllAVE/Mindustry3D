# A2-16b.1 — Conveyor seams, corner guards and filter colors

Baseline: owner-accepted A2-16b `b2f02d54ed80f8f3ec45a72ac0c2baaa52bf2bc5` on `main`.
This is a local visual correction, not a published version or replacement Alpha artifact.

## Confirmed causes and corrections

1. **Resource cropping:** the previous renderer clipped every conveyor item sprite to its owning tile. An item approaching a legitimate outgoing seam therefore lost part of its texture before transfer. Conveyor, Titanium Conveyor and the purple native **Armored Conveyor** share this path (vanilla 160.7 has no separately named Thorium Conveyor). The renderer now retains the complete item quad/UVs across an actual compatible, same-team, same-floor conveyor connection. It expands only the connected edges by the existing icon half-width. Closed ends, unrelated neighbors and other floors retain clipping; ordinary solid geometry still occludes cargo. Position, size, queue, throughput and native update methods are unchanged. Plastanium's existing cargo/pallet implementation is unchanged.
2. **Open corners:** the old guard mask always opened the opposite/rear edge, even when the real feed entered from the side. This left a turn resembling an open three-way junction. The mask now reads actual incoming belt directions and native compatibility from floor-local neighbors. Its fallback rear mouth applies only when there is no actual input. Left/right bends receive the missing cosmetic guard while valid inputs remain open. Existing cached guard meshes and all LODs are reused, including Plastanium; no new collision or transport restriction is added.
3. **Distributor ports:** inspection of the installed 160.7 native definition confirms a **2×2** footprint. The earlier three-mouth profile was incorrect. `ResourcePortGeometry` now receives two mouths per side for Distributor, with the original footprint and roof intact.
4. **Live selected-item colors:** Unloader reads native `sortItem`; Item Source reads native `outputItem`. The shared native-animation adapter draws Unloader's original center texture with the selected item's color, and Item Source's original roof over a selected-item-colored backing. Clearing uses the native unconfigured presentation. Upper-floor generic boxes omit their static roof for these two types so it cannot hide or retain a stale selection. No cached colored texture or per-frame texture generation is used. Original bodies, menus, filters and item production/transfer logic are retained.

## Scope

Four existing runtime classes change: `LogisticsModelRenderer`, `LogisticsModelGeometry`, `NativeBlockAnimationAdapter`, `LayerWorldRenderer`. One new native regression program and the diagnostic-build task selector support this correction. No camera/input, physics, combat, networking, save-format, block-definition, drill-model or construction-scheduling changes. No new bindings or dependencies. The new JAR still requires identical multiplayer peers under the existing strict fingerprint checks.

## Validation and limitations

See `A2-16b.1-TEST-MATRIX.md` and `A2-16b.1-VALIDATION.json` for final counts, hashes and whole-renderer measurements. Automated native tests, actual Windows SDL/OpenGL scripted scenes and physical gameplay acceptance are reported separately. Test worlds/profiles are disposable; primary saves and all previous artifacts are preserved.

Cargo remains native sprite art. It can be physically hidden by a valid guard, nearby solid object, platform or roof. Unsupported non-vanilla belt types do not automatically acquire a new model. Plastanium keeps its previously documented destination-heading pallet rotation. Distant LODs omit tiny tunnel facets. Clearing Unloader/Item Source reproduces native unconfigured artwork, rather than inventing a new color. Physical Linux, owner input/visual acceptance and a real two-computer session remain pending for this correction.

Import the diagnostic JAR through the normal Mods → Import Mod workflow; restart with one copy enabled. Follow the three steps in `A2-16b.1-MANUAL-TEST.md`. No release has been pushed or published.
