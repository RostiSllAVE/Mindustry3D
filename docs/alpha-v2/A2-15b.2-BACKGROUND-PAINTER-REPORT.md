# A2-15b.2 — Interactive background painter

Baseline: accepted A2-15b `7093055`, existing `main`. The initial bounded editor, presets and per-map storage already existed; this pass extends them instead of rebuilding them.

## Internal checkpoint 1 — brush data and geometry

Added gesture-scoped strength, Raise/Lower/Smooth/Flatten, distinct Shallow Water and Lake brushes, and sparse Industrial motifs. A gesture stores its source mask and maximum influence per node, so repeated pointer events or holding still do not amplify a stroke. Strength blends up to two material identities per node without reopening holes in islands. Height tools use the original base terrain and a fixed pre-stroke snapshot; smooth reads neighbours from that snapshot. Height is bounded by brush radius and the existing 240-tile limit; custom relief is also tapered near the native border. Broader custom shoreline ramps prevent abrupt full-height shore walls. Auto/Manual generation is unchanged.

Painted Grass uses shrub LOD; Forest retains tree silhouettes. Painted sand/rock/volcanic regions can receive bounded outcrops; Industrial creates at most six decorative mesh motifs, no buildings/entities. These use the existing cached scenery mesh and feature machinery.

Local profile v2 adds a second material ID and blend weight. Maximum reads are 192KiB, populated profile142,642 bytes; mask142,578 bytes and bounded32-stroke history estimate4,847,652 bytes. Exact v1 channel migration and v2 roundtrip are tested; old profiles remain readable and ordinary saves/network protocol are untouched. At most two materials per node are retained: a third overpaint uses the previous dominant material, not an unlimited Photoshop-style layer stack.

Targeted validation:22 programs on Java17 and stock Steam25; additional detail/height fixture passes1,921,233 checks on Java17. Brush fixture passes8,561 checks. Full final suites and physical acceptance are reported separately after the UI/viewport checkpoint. Intermediate graphics exposed incorrect Arc framebuffer nesting; corrected before final validation. The first 960×600 viewport render also exposed wrapping/width problems, being corrected in the UI checkpoint.
