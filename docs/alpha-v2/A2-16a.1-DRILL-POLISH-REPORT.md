# A2-16a.1 — Drill resource ports and operating lights

Continues accepted A2-16a (`09c9cff`) on `main`. Visual-only follow-up; no published release is replaced.

## Changes

- `ResourcePortGeometry` supplies reusable normalized, faceted resource tunnels. Each footprint cell has one mouth on each of four sides: Mechanical 2, Pneumatic 2, Laser 3, Airblast 4 per side (8/8/12/16 total). Centers line up with neighboring tile centers. A native-textured roof, piers and headers replace the old uninterrupted foundation sides. Dark recessed backs, jambs and ceilings give the mouths real depth. Frames use the same native chassis material as the body, not the red annotation color.
- The generator is separate from drill-specific machinery and can be reused by future resource blocks. It creates no simulation ports, routing restrictions, item entities or transfer events. Existing ore/conveyor rendering and native dumping remain responsible for resources.
- Laser's four opaque hammer housings previously extended to 73% of model height and contained no separate moving shafts. They now end at 56%; four square metal shafts extend from 51% to 77%, joining the upper assembly. The existing native-time piston transform moves them, at near and medium LOD. The physical block height and collision shape are unchanged.
- All four drills have native-palette status rails above the mouths. Laser/Airblast accent bands share the status brightness. Brightness is `0.18 + 0.82 * activity`, where activity uses enabled state, real efficiency, dominant ore/cells, item capacity and vanilla warmup. Full, disabled, unpowered or ore-less drills dim; normal work retains the original copper/gray/purple/orange identity. Brief gaps between native item dumps do not blink the rails. Airblast retains its existing warmup rim.

## Rendering and scope

Foundation/tunnel/light vertex arrays are generated only when a drill type's existing model cache is created. All parts enter the current native-atlas batch; there are no new GL passes, textures, dependencies or per-drill mesh caches. Near arches have four curved facets, medium arches two. Far LOD remains the accepted simplified body/icon and does not show individual ports or status strips.

No input, terrain, unit, mining rate, resources, storage limits, construction, networking, save formats or other block families change. Existing active pistons and rotor timing are preserved. New mouths are deliberately shallow visual tunnels, not physical holes in the collision model.
