# A2-16o polish — native turret heads and aircraft propulsion

Baseline: accepted A2-16o `36b0ee4` on `main`. This is a local visual diagnostic, not a replacement public release. No shader, gameplay, network, camera/controller, collision, placement, save-format or balance changes.

## Repair Point / Repair Turret

The A2-16o utility profiles mapped parts of the complete repair-head sprite onto separate box-shaped pieces. Those pieces hid/cropped parts of the art and did not reproduce the native turret's base/head composition.

Both blocks now use the existing native-atlas turret pipeline: their original `baseRegion` is seated at the real floor, and their complete original head region gets cached alpha-silhouette top, underside and side geometry. Original pixel dimensions and native `RepairPointBuild.rotation` supply proportions and yaw. There is no partial head UV crop or stretched utility box. The same path is used at Z0 and by actual upper-layer proxies; presentation bounds include the overhanging head. The obsolete repair utility templates are not generated by the runtime renderer.

Native targeting, healing strength, beam endpoints, range and health updates are untouched. Focused native/GPU checks prove real HP healing at Z0/Z1/Z5, independently turning heads, full visible art and cache reuse.

## Additional turret polish

- **Parallax and Segment:** replace generic body/flat-head fallback with the same complete native base and separately yawing volumetric head.
- **Arc, Lancer, Meltdown, Wave, Tsunami, Hail and Ripple:** add one narrower lower armored contour beneath the existing alpha-shaped head. The contour is 80% of the head width/length and adds 0.65 times the existing extrusion depth below its underside. Exterior side faces connect the contours; the old underside becomes the new lower cap. There is no hidden duplicated intermediate cap or second top texture.
- The original roof vertices, UVs, mount pivot, muzzle coordinates, native top/liquid/heat decals and recoil transforms stay exact. The supporting base is shortened to clear the new downward shell. The seven selected vanilla definitions have no moving `RegionPart` children, avoiding the accepted moving-wing arrangements.
- **Duo, Salvo and Cyclone** retain their accepted model shapes and animation transforms. Other specialized/procedural turret drawers retain their previous fallback; this is not a claim that every turret has a bespoke new model.

Immutable silhouettes and lower shells are generated once per atlas region/cache lifetime, then transformed into the existing atlas stream. No per-instance textures or per-frame topology generation are added. Exact geometry and performance measurements are in the test matrix.

## Aircraft exhaust

`FlyingEngineVisuals` reads native `UnitType.engines` offsets, rotations, radii and colors, with the native `engineOffset`/`engineSize` fallback where the list is empty. Hardpoints and ejection directions follow the same yaw/pitch/roll basis as the rendered aircraft, including the controlled presentation pose.

The effect uses the existing closed octagonal volume geometry and emissive dynamic batch. Nearby jets have two stepped outer sections and a short bright core; the existing high-detail-distance setting reduces distant jets to one section. Length responds to speed and deterministic time/ID pulses, so hovering and moving aircraft differ without particle entities, random state, physics or damage. Engine reach participates in conservative culling. Normal world depth remains enabled: an obstacle may correctly hide a jet.

Only live, added, actually flying native aircraft are eligible. Existing grounded-unit boost effects are unchanged. The controlled aircraft's exhaust is hidden together with its own hidden FPV body; visible other aircraft retain it in FPV. Death/removal stops submission immediately. There is no heat distortion, bloom/shader change, persistent trail or new exhaust simulation.

## Validation and limitations

See `A2-16o-POLISH-TEST-MATRIX.md`, `A2-16o-POLISH-VALIDATION.json` and `A2-16o-POLISH-MANUAL-TEST.md` for evidence and owner steps. All launches use the clean standalone **Mindustry 160.7** SDK in isolated profiles, without Steam. Tests use complete **Java 17.0.20.1** and stock bundled **Java 25.0.1**; both run the same player JAR. Test-only fixture overlays are identified separately from that importable JAR.

Physical owner gameplay/import acceptance, physical Linux GPU/input, a real two-computer session and GPU timer measurements are **NOT TESTED** in this pass. Existing Windows windowed presentation issues remain; use fullscreen for visual acceptance. The exhaust is deliberately hard-edged and lightweight. Owner judgement of its appearance remains necessary.

The initial 50-aircraft fixture failed because its native core cap allowed only eight Flares. Raising only the disposable test map's cap fixes the fixture; the production unit cap is unchanged. Failed debug runs are retained and excluded from final performance evidence. The older broad paused support-effects helper has its previously documented baseline repair-snapshot failure; focused actual healing checks and all regression programs pass, so no speculative gameplay/network fix was introduced.
