# A2-16b.1 — Three owner checks

Import `local/a2-16b-polish/test-kit-final/mindustry-fpv-a2-16b-polish-diagnostics.jar` through Mindustry 160.7 Mods → Import Mod, enable one copy and restart. Use a disposable map/backup; Windows fullscreen is recommended. No new controls. The same JAR uses existing Windows/Linux paths, Java 17 or stock Steam Java 25; physical Linux acceptance is pending.

1. Feed copper, lead and another item along normal, titanium and purple Armored conveyor lines. Inspect the joins slowly from low FPV and top-down Tab. Add left/right turns in each direction, also on Plastanium: the unused outside/back edge should have a wall and valid item entrances must remain open. Repeat on a supported Z3+ platform with a Z0 line below. Real walls/platforms should still hide items behind them.
2. Inspect Distributor on Z0 and an upper floor: each side must show exactly two recessed tunnels. Connect conveyors and check ordinary routing. Glance at the accepted drills and other logistics models for regressions.
3. Change Unloader and Item Source from copper to lead (or a visibly different resource), then clear their configuration. Their center/roof color should follow immediately, on Z0 and Z3+. Save/reload, switch F5/Tab and check ordinary placement/removal, F3 pause and Alt-click blueprint priority. Actual unloading/source output must still obey its normal configuration.

Report remaining cut cargo, missing corner guards, stale colors, flicker or dense-line slowdowns. The automated fixture advances native inventories, configures actual buildings, draws real OpenGL scenes and reloads a disposable save, but does not constitute physical mouse/menu or remote multiplayer acceptance.
