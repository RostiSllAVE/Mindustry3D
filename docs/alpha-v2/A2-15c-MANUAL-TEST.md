# A2-15c — owner visual checks

Unreleased diagnostic; use a disposable profile or backed-up save. Import the supplied
`mindustry-fpv-a2-15c-diagnostics.jar`, keep only one copy enabled, restart Mindustry
160.7. Windows and Linux use the same JAR. Fullscreen remains recommended on Windows.
No commands, extra Java installation or developer resources are required to play.

## Three essential checks

1. **Mixed terrain and depth:** On a temporary sandbox/editor map containing native
   **Space** floor beside stone/sand (include a small isolated patch and a larger area),
   press F5. Look down, sideways at the edge, rotate and fly above it. Stars must stay
   oriented in the world and remain inside the designated floor; ordinary dark/volcanic
   ground stays ordinary. Put a building/unit beside it and an existing Z3 platform
   above it using the normal permitted construction rules. The platform, its underside
   and units must cover the stars. Do not expect new placement permissions or falling.
2. **Backgrounds:** Tab → Background settings: compare Auto, Manual Space, Manual Void
   and Custom with a Space/Void patch beside forest/ocean. Local cosmic paint removes
   local landscape and reveals a cosmic field; non-cosmic painted scenery remains.
   Whole Space/Void presets also change the sky. Local paint deliberately retains the
   shared planetary sky above it. Compare day/night; stars should not flicker randomly.
3. **Fallback and persistence:** Settings → FPV flight → **Cosmic floor effect** OFF,
   then ON. OFF restores the original native-floor rendering; background presets are
   independent. Check F5, Tab, normal placement/priority, menu and mouse release, save,
   reload, then enter another sector. Previous mechanics and the setting must survive.

Record screenshots and GPU/OS if a seam, missing underside or performance problem appears.
Physical Windows/Linux visual acceptance and real remote multiplayer remain owner tests.
The effect does not make native Space/Empty floors buildable or change their collision.
