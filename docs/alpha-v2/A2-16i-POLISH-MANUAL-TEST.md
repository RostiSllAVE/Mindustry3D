# A2-16i follow-up — Three owner checks

Import `local/a2-16i-polish/test-kit-optimized/mindustry-fpv-a2-16i-polish-diagnostics.jar`
through Mindustry160.7 Mods → Import Mod, replace the local test build and restart.
Use a disposable map or backed-up save, with one enabled copy. Windows fullscreen
is recommended. The same portable JAR is supplied for Windows/Linux; source ZIP is
not the mod. No new controls or separate Java installation are required.

1. **Force Projector.** Look closely from above and the side while moving the
   camera: the cap must not flicker. Power the shield, take actual hits, disable,
   deplete and recharge it. The small hexagonal globe above the emitter should
   indicate activity and disappear while disabled/broken. It does not extend
   protection: the larger existing finite protective boundary remains authoritative.
2. **New bodies and light.** Compare Shock Mine, Illuminator, Launch Pad and
   Landing Pad from above and low FPV, also on Z1/Z3/Z5 with ordinary headroom.
   Change the lamp's native color, remove power and disable it. Check loading
   arches and distinct sender/receiver silhouettes. Copies must have empty stores;
   save/reload must preserve real source inventories and normal operation.
3. **Actual shipments.** Fill and supply a Launch Pad and trigger a native export;
   observe an upward pulse. Start a valid Landing Pad import and observe a downward
   pulse ending at its own deck. Repeat upstairs and at identical XY on separate
   floors. Check pause/resume, F5/Tab, menus and a sector/save reload. No beam should
   appear just because a pad is empty/configured. Report any missing remote-client
   effect separately from resource transfer; normal campaign rules still apply.

Physical owner Windows/Linux acceptance and real two-computer animation checks
remain pending. A transient ground launch may be deliberately omitted if its native
payload cannot be assigned to a unique source; no fictional transfer is substituted.
