# A2-15c.1 — space appearance owner checks

Import `mindustry-fpv-a2-15c-polish-diagnostics.jar` in Mindustry160.7, keep only one
copy enabled and restart. Same JAR for Windows/Linux. Fullscreen recommended on Windows;
use a disposable map or backed-up save. This remains an unreleased diagnostic.

## Controls

In a loaded world: Tab → Background settings → Open Background Editor →
**Sky / map appearance**. Available controls:

- Show planet.
- Show sun.
- Animate day / night. OFF uses the Fixed time slider; game time itself is unaffected.
- Full space environment: cosmic sky without atmospheric horizon or distant landscape.
- Show map boundary: optional thin boundary, OFF by default.

The submenu's Back button returns to the editor. Use **Preview 3D** or **Apply** in
that editor to display the staged changes; Apply saves them locally for this map.
Cancelling the main editor discards unapplied changes. The same appearance submenu
opened directly from Background settings applies changes immediately.

## Three visual checks

1. On a map containing Space/Empty floor and solid islands, enable Full space,
   hide planet/sun, then enable each separately. Disable day/night animation and move
   Fixed time. Restore ordinary atmosphere and automatic/painter scenery: previous
   paint must return. Save/reload to verify the appearance settings persist.
2. View the map edge low and from above with Show map boundary OFF, then ON. The old
   broad white/blue sky gap should be gone in both cases; ON adds only a thin outline.
   At high altitude this thin line can alias/become faint. The white read-only map
   rectangle in the 2D painting canvas remains as an editing guide.
3. Fly beside solid floor islands surrounded by native Space/Empty. Look obliquely
   and at ground level: there should be textured, tapered rock extending below Z0.
   Check ordinary building, a Z3 platform, F5/Tab and save/load. Top surfaces and all
   collision/building heights remain unchanged; the new rock is visual-only.

Underside detail is a bounded eight-tile band near real cosmic tiles, not a physical
negative-Z terrain system or a complete solid interior for arbitrarily large landmasses.
The editor's central 3D map reference is still flat; inspect island undersides in the
actual FPV world. Linux input/rendering and remote multiplayer need physical acceptance.
