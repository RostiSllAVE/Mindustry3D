# A2-15a.1 — Manual visual check

Install `local/a2-15a-1/test-kit/mindustry-fpv-a2-15a-1-diagnostics.jar` through Mods → Import Mod, then restart. Use a backup/disposable profile. Keep only one enabled copy. The same JAR is intended for Windows/Linux; physical Linux acceptance is pending. Fullscreen remains recommended for the known Windows windowed presentation issue.

No new controls. F5, Tab, F3, F7, Alt+wheel and existing construction priorities remain unchanged. Settings → FPV flight → Automatic biome horizon controls the new background; OFF shows legacy mountains, not the previous A2-15a materials. For an exact before/after comparison use the preserved A2-15a JAR separately or the kit's comparison screenshots. Do not overwrite the earlier artifact.

1. **Desert, water and mixed corners:** fly low along the edge, rotate through corners, then inspect oblique and high overhead views. The sand/snow pattern should repeat at tile scale instead of stretching into streaks. Check for cracks, colour fans, atlas bleed, flashing water joins and obvious texture jumps. A high-view native detail rectangle and different distant-water wave presentation can still be visible.
2. **Snow/rock and forests:** inspect mountains from the side/oblique view and above; look for unnatural spikes or broad flat triangles. Forests should show varied clusters, heights, orientation, trunks and conifer silhouettes, rather than two regular rows/diamonds. Check feet on slopes. Compare frame behaviour on your hardware; try night too.
3. **Normal play/lifecycle:** use F5, Tab, build, F3 pause/resume, Alt-click blueprint priority and3D selection/copy/paste. Save/reload and switch maps/sectors; old scenery must disappear and the same map should regenerate consistently. Decorative ground must not extend build/collision/AI boundaries. On Linux repeat the first two checks; if testing multiplayer, all peers need this exact diagnostic JAR.

Report map/edge/altitude/time and a screenshot for remaining problems. Automated tests and scripted Steam SDL captures passed, but owner visual acceptance, physical Linux and independent multiplayer are still pending.
