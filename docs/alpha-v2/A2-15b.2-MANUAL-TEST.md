# A2-15b.2 — Owner acceptance

Import the local `mindustry-fpv-a2-15b-2-diagnostics.jar` through **Mods → Import Mod**, keep one enabled copy and restart. Windows/Linux use the same JAR; no extra player Java or developer tools. Use backups/disposable saves; Fullscreen is recommended for the earlier Windows presentation issue. Physical acceptance is still required.

1. Open a world, **Tab → Background settings**. Select **Manual → Ocean**, then **Custom → Open Background Editor**. North is up; the white native-map rectangle is read-only. Palette scrolls: paint Island outside the north edge, then Grass/Forest on it, a Mountain ridge farther behind, and Beach/Shallow/Lake at the coast. Try Industrial on dry land. LMB-drag paints; RMB/MMB-drag pans; wheel zooms. Painting inside the map or beyond supported limits must do nothing there (red cursor).
2. Test Strength25% versus100%, separate weak strokes versus holding still, and soft/hard Falloff. Try Raise/Lower, Flatten and Smooth. Height/step is radius-limited; Smooth ignores it. Native-border taper and rounded mountains/island skirts should avoid an abrupt wall. Ctrl+Z /Ctrl+Y (Ctrl+Shift+Z) and Undo/Redo should restore strokes without game commands. Water must stay flat, with visibly different shallow/lake/ocean beds.
3. **Preview 3D**: orbit using LMB-drag, pan using RMB/MMB and wheel for distance. The native map is a flat reference; the surrounding island/trees/ridge must be real3D. **Edit map** returns to strokes; Preview again to refresh. Cancel/Escape must restore the previously applied background. Apply should show a saved-local message. Clear is undoable/staged; Reset Auto applies Auto but keeps the mask available in Custom.
4. Apply a design, save, quit/restart and reopen. Switch maps/campaign sectors and return; each should retain its local design. Existing v1 art should still load, upgrading locally only on Apply. Check F3/F4/F5/Tab outside the dialog, mouse capture in flight versus editor/menu, Alt+Tab return, blueprint priority and construction/selection/copy. Background editing must never change blocks, resources, collisions or unit commands. On Linux test the real X11/Wayland session; with a friend test different local scenery without shared files. Those physical platform/multiplayer checks are pending.

Report map/sector, selected tool/strength/radius, view angle and a screenshot for visual issues. Per-map data stays in the Mindustry data directory under `mindustry3-backgrounds`, separate from native saves; valid previous `.bak` is retained. Invalid/unsupported data recovers a backup or uses Auto. Disk/profile-limit failure leaves edits session-only with a visible status. Identical named terrain clones share art; renaming/editing sampled native floors can select a new profile. This is an unreleased diagnostic, not a public Alpha overwrite.
