# A2-17a — three essential owner checks

Import `local/a2-17a/test-kit/mindustry-fpv-a2-17a-diagnostics.jar`, replace the previous mod and restart with one Mindustry³ version installed. Fullscreen is recommended for the existing Windows windowed-presentation issue.

1. **Compare the same mountain.** Settings → FPV flight → **Mountain geometry style** → Smooth / Blocky / Hybrid. Watch from low FPV, side/oblique and above. Smooth is the initial default. Blocky should show real ledges; Hybrid should show both slopes and rocky steps. Changes apply without restarting. For a broad high-altitude comparison, temporarily increase **3D high-detail distance**; terrain outside that tier intentionally stays Smooth. Keep the independent world draw distance unchanged.
2. **Inspect contacts and boundaries.** Try snow, desert and volcanic rocks, a tall massif, a small isolated rock and a mountain beside water. Inspect ore, trees, artificial walls/factories and Z1/Z3 platforms beside the cliff. Cross chunk/detail boundaries slowly while flying; look for holes, floating faces, smeared side textures or covered buildings. Physics/picking retain the original smooth triangles: decorative roof differences up to 0.35 tile are expected. Use Smooth when exact visual contact is preferred.
3. **Check stability and persistence.** On a dense map, compare warm performance, switch F5/Tab, place a normal block and a platform block, and use the accepted 3D selection/copy/paste controls. Save/reload, visit another campaign sector and restart once; the local style preference should remain. Verify cliffs and supported structures keep their gameplay behavior. Revert to Smooth at any time if the new near-detail geometry is too costly.

Report style, map, view/distance and a screenshot for artifacts. Automated Windows renders do not replace your visual acceptance, physical Linux testing or a real two-computer session. No new digging, negative construction floors, terrain destruction or voxel climbing is implemented.
