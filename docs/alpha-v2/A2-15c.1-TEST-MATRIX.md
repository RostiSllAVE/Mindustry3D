## Rendered toggle differences

- planet: 8148 pixels.
- sun: 460 pixels.
- border: 305 pixels.

The thin map outline can alias at distance; it is not the old four-tile sky gap.
Underside detail is bounded to an eight-tile band and is visual, with no new physical
volume/collision. Large interiors are not a complete solid asteroid model.

Final graphics use the ordinary tested JAR plus a lab-only replacement SmokeHarness;
only that class differs, with exact source/replacement hashes in each manifest. The
importable JAR contains its normal harness. Raw logs/profiles/saves/game files are not
included in the test kit. Timing fields are diagnostic only: no before/after performance
benchmark or FPS improvement is claimed. No per-frame mesh regeneration was observed
for already cached geometry during the scripted runs.
