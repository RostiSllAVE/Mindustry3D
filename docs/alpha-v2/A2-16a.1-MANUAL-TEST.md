# A2-16a.1 — Owner checks

Import `local/a2-16a-polish/test-kit-ready/mindustry-fpv-a2-16a-polish-diagnostics.jar` through Mindustry Mods → Import Mod and restart. This is an unreleased diagnostic for Windows/Linux, not an update to published Alpha assets. Back up a save before testing; fullscreen is recommended for the previously identified windowed display issue.

1. Place Mechanical, Pneumatic, Laser and Airblast drills on ore. Inspect all four sides from low FPV and Tab/Build views: expect respectively 2, 2, 3 and 4 gray body-colored tunnel mouths per side. Attach conveyors at several edge cells; native ore output should work as before. Repeat one drill on Z2.
2. Supply required power/liquid and watch the Laser Drill while operating: four exposed metal shafts should move with its mechanisms. Check top/oblique views and both close and medium distance; no new controls are required.
3. Let each drill fill by blocking output, then reconnect output; also toggle it off/on. Native-color rails should dim when full/stopped and brighten during work. Confirm resources continue normally, then save/reload and use F5/Tab. A short delay due to normal warmup is expected; distant LOD intentionally omits these small details.

Report any floating arches, missing shafts, unreadable lights or excessive cost in a dense mining field. These physical gameplay checks have not been substituted with automated acceptance.
